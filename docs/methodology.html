Methodology

Balance

Current address balance is calculated from unspent transaction outputs (UTXOs): 

SUM(amount) WHERE spent = 0 GROUP BY address

The displayed balance therefore represents the current unspent amount indexed by the local Qubitcoin node.

Received and Sent

Received values are derived from recorded transaction outputs. Sent values are derived from recorded transaction inputs.

Transaction flows

The Bubble Map can reconstruct probable flows between addresses by proportionally relating transaction inputs to transaction outputs. This is a visualization heuristic rather than proof of ownership, control or intent.

Exchange attribution

Gold markers retain the project's two known exchange reference addresses. Orange dashed markers indicate unconfirmed research annotations and are excluded from known-exchange totals.

Potential SafeTrade Wallet indicates repeated common-input observations with the known SafeTrade reference. This suggests shared control, but collaborative transactions and an incorrect reference label can invalidate the inference. It is not independent ownership confirmation.

SafeTrade-linked Wallet records an observed connection only. A single large incoming transaction with no later spending can fit a private holder, a team wallet or exchange cold storage. Ownership remains unknown. Select a wallet to read its reviewed evidence. Current attribution annotations also apply when viewing older balance snapshots.

A visual connection between two addresses does not automatically prove that the addresses belong to the same person, organization or entity.
