Public SafeTrade REST snapshots. Ticker, trades and order book refresh every 15 seconds; candles every 60 seconds. Failed requests use backoff up to 120 seconds. Updates pause in a hidden tab.

Checking market identity: Qubitcoin (qtc), quoted in USDT.

No close × volume estimate is presented as actual turnover. This is an independent community project, not an official exchange or Qubitcoin service.

Sources & calculation notes

Official Qubitcoin project → official explorer and original logo. SafeTrade API documentation.

Default parameters: EMA 20/50 (SMA seed), SMA 50, Bollinger 20/2 (population standard deviation), Wilder RSI 14, MACD 12/26/9, Wilder ATR 14, Stoch RSI 14 with K/D smoothing 3/3. Periods can be changed in Indicators & settings. UTC session VWAP uses loaded candle HLC3 × volume and approximates trade-level VWAP. Indicators require sufficient consecutive candles; missing intervals reset indicator warmup. A current candle, when returned by the exchange, is provisional. No missing bars are fabricated.

“Connected” means the browser received and validated a recent response, not that the exchange guarantees real-time accuracy. The API supplies no ticker timestamp; check time is local receipt time. Candle open and latest trade timestamps are shown separately. Stale threshold: 45 seconds for market snapshots, 150 seconds for candles. Candle history older than two selected intervals plus 150 seconds is marked stale separately. Older trades can reflect an inactive market.
