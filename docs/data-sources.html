Data Sources

Qubitcoin blockchain

The Bubble Map is based on publicly available on-chain data from the Qubitcoin blockchain.

Local blockchain index

The public visualization is generated from an indexed copy of on-chain transaction and UTXO data. The published dataset contains only the information required for the public visualization.

Public dataset

The published graph shows addresses with a positive current unspent balance. Links are aggregated heuristic relationships between those funded addresses and are included when their recorded value meets the dataset's displayed minimum-flow threshold. Newly funded addresses appear after the next successful scan and publication; addresses with no remaining balance are removed. The source database and its local infrastructure details are not published.

Market data

The displayed CoinMarketCap quote is provided by its embedded ticker widget. The widget's price is displayed separately and is not used in another calculation on this site.

Emission schedule

Scheduled issuance is calculated from the indexed block height using a starting reward of 50 QTC and a 210,000-block halving interval. It is a protocol schedule estimate. The displayed circulating supply estimate excludes the unspendable genesis reward, but block height alone cannot identify lost, burned, or otherwise inaccessible coins.

The presence of an address or transaction relationship in this visualization is not an attribution of ownership.
